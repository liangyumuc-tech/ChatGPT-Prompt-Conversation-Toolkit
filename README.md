# ChatGPT Prompt & Conversation Toolkit

A lightweight open-source toolkit for managing prompts and conversations with OpenAI models.

> **Status:** Early development / pre-release

## Overview

ChatGPT Prompt & Conversation Toolkit is an open-source Python toolkit designed to make it easier to create, organize, reuse, and manage prompts and conversations with OpenAI models.

The project focuses on simplicity, portability, and practical use for developers and advanced users.

## Planned Features

* 📝 Prompt creation and management
* 💬 Conversation management
* 🔄 Reusable prompt templates
* 💾 Import and export of conversations
* 📄 Markdown export
* 🐍 Python API
* 💻 Command-line interface (CLI)
* 🔐 Secure API key configuration
* 🧪 Automated tests
* ⚙️ Continuous integration with GitHub Actions
